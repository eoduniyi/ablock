Proposition 1

Evaluating pairwise distances across $N$ particles in a metric proximity graph $G_\varepsilon$ incurs $\binom{N}{2}$ operations ($\mathcal{O}(N^2)$).

In an A-Block, decoupling relational edges via the empirical measure transformation $\mathcal{T}$ and localized Clifford score updates $\mathbf{f}_i(\mathbf{x}_i) = (\sigma_i I - \kappa_i)\nabla V_\theta(\mathbf{x}_i)$ reduces per-frame sampling complexity to strictly $\mathcal{O}(N)$.

Proof Sketch. In the metric graph regime, the adjacency matrix $\mathbf{A}_{ij} = \mathbb{I}(\|\mathbf{x}_i - \mathbf{x}_j\| < \varepsilon)$ requires $\binom{N}{2}$ all-pairs evaluations.

Under transformation $\mathcal{T},$ each particle $\mathbf{x}_i$ is updated independently via the local neural gradient $\nabla V_\theta(\mathbf{x}_i)$ and algebraic rotor $(\sigma_i I - \kappa_i),$ requiring exactly $1$ forward-backward pass per particle.

For an ensemble of $K$ modular A-Blocks ($A_1, \dots, A_K$) with $N_k$ particles each, total compute cost scales as $\sum_{k=1}^K \mathcal{O}(N_k) = \mathcal{O}(N_{\text{total}})$.
